# Particle effects

Particle Studio saves game event assignments here as `<EVENT>.pfx`, for example
`HIT.pfx` or `SHOCKWAVE.pfx`. Each file contains its settings and optional image.
You can keep your other saved `.pfx` designs here too; only files named for a
supported game event are automatically loaded by the game.

Launch `ParticleEditor.bat` from the project root to create or edit effects.
Restart the game after assigning an effect. Copy this folder with the project
when sharing your effects with other players. No assigned files means the game
uses its built-in effects.

See [the editor guide](../README.md#particle-studio) for controls and file limits.
