# Particle shape presets

Reusable triangulated OBJ particle meshes live here. Use Import preset or Save
shape preset on Particle Studio's Particle effects tab, then select a name from
Shape preset. Refresh discovers files added while the editor is open.

Imports are centered and normalized. Files placed here manually keep their scale.
Limits: 512 vertices, 256 triangles, 256 KB per OBJ. Geometry only.
Selected meshes are embedded in saved .pfx effects; the game does not need this
library folder to render those effects. Editing a shape does not overwrite its
preset until you explicitly save it again.
